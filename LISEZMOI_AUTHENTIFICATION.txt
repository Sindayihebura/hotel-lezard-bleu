  Le code est prêt, mais vous devez configurer les dashboards :

  1. Supabase Dashboard
     → Activer Email Provider
     → Activer Google Provider
     → Configurer les URLs autorisées

  2. Google Cloud Console
     → Créer un projet
     → Créer OAuth Client ID
     → Copier Client ID/Secret dans Supabase

  3. Netlify Dashboard
     → Ajouter 4 variables d'environnement :
        - SUPABASE_URL
        - SUPABASE_ANON_KEY
        - SUPABASE_SERVICE_ROLE_KEY
        - SITE_URL

  4. Déploiement
     → Utiliser Netlify CLI : netlify deploy --prod
     → OU connecter votre dépôt Git

  ⚠️  NE PAS faire de drag-and-drop de dist/ !
      Les Netlify Functions ne seraient pas incluses.
